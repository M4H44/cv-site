About Me

I am a backend developer focused on Java and Spring Boot; on the frontend I work with React and TypeScript.

As part of a team I develop a corporate attendance and shift management application (Spring Boot, React, PostgreSQL). The rewrite of the original PHP application is complete and I now design and build new modules from scratch — user management, audit log and employee training. I own them end to end, from database design through authorization and GDPR to the frontend. The code is covered by more than 350 automated tests (JUnit 5, Vitest).

I use AI tools (Claude) for implementation, debugging and writing tests. I always review and test the output — only code I understand and can defend goes in.

In addition, I am part of the development team of the Školium learning platform (Laravel, Vue 3), where my changes go straight to production via GitHub Actions.

I have also built my own projects in Node.js and Express — multi-role web applications with MySQL and Docker, taken from database design all the way to a working demo.

Years of management experience in the automotive industry gave me habits that are not taught in IT — analytical thinking, ownership of results, and the ability to work under pressure. My move into IT is deliberate and goal-driven.

Looking for a Java or fullstack developer position, including remote work or starting part-time. Part-time studies allow me to work full-time as well.

Alongside work I study Applied Informatics at Matej Bel University (3rd year, part-time).
