Corporate app – attendance & shift management (Continental)
Main project 8 modules completed

Web application for managing attendance, shift planning and related processes in a corporate environment. Five modules are a rewrite of a legacy PHP system to a Java (Spring Boot 4) + React 19 architecture in TypeScript; three more I designed and built from scratch.

  • five modules rewritten from the legacy PHP system: shift calendar, attendance, attendance rules, absences and overtime, qualification matrix
  • three modules designed and built from scratch, with no PHP counterpart: user management, audit log and employee training
  • training: HR uploads materials (PDF, video up to 500 MB) and assigns them by company, department, role, team or individual; employees confirm receipt with their password
  • audit log immutable at database level (triggers), old and new values in JSONB, IP address, deletion only after export to a file
  • GDPR consent: without consent a request is recorded anonymously, the backend decides whether the name is shown
  • password security: 6-month expiry, last 3 passwords blocked (compared via BCrypt) and a similarity check against the previous password
  • role hierarchy and endpoint-level authorization (Spring Security)
  • login attempt rate limiting
  • routing (React Router) with role-based route guards
  • PostgreSQL database design, versioned migrations (Flyway) including views
  • server-side PDF report generation (OpenPDF) — qualification matrix
  • more than 350 tests I wrote myself, unit and integration, on backend and frontend (JUnit 5, MockMvc, @DataJpaTest, Vitest)
  • Docker environment, Git workflow
