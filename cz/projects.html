Firemní aplikace – správa docházky a směn (Continental)
Hlavní projekt 8 dokončených modulů

Webová aplikace pro správu docházky, plánu směn a souvisejících procesů v podnikovém prostředí. Pět modulů je přepisem původní PHP aplikace do architektury Java (Spring Boot 4) + React 19 v TypeScriptu, další tři jsem navrhl a naprogramoval od nuly.

  • pět modulů přepsaných z původní PHP aplikace: kalendář směn, docházka, pravidla docházky, absence a přesčasy, matice kvalifikací
  • tři moduly navržené a naprogramované od nuly, bez předlohy v PHP: správa uživatelů, auditní log a školení zaměstnanců
  • školení: HR nahrává materiály (PDF, video do 500 MB) a přiřazuje je podle firmy, střediska, role, týmu či jednotlivce; zaměstnanec převzetí potvrdí heslem
  • auditní log neměnný na úrovni databáze (triggery), stará i nová hodnota v JSONB, IP adresa, smazání až po archivaci do souboru
  • GDPR souhlas: bez souhlasu se žádost eviduje anonymně, o zobrazení jména rozhoduje backend
  • bezpečnost hesel: platnost 6 měsíců, zákaz posledních 3 hesel (porovnání přes BCrypt) a kontrola podobnosti s předchozím heslem
  • hierarchie rolí a oprávnění na úrovni jednotlivých endpointů (Spring Security)
  • omezení počtu pokusů o přihlášení (rate limiting)
  • routování (React Router) s ochranou cest podle rolí
  • návrh databáze v PostgreSQL, verzované migrace (Flyway) včetně pohledů
  • generování PDF sestav na backendu (OpenPDF) — matice kvalifikací
  • více než 350 vlastních unit a integračních testů na backendu i frontendu (JUnit 5, MockMvc, @DataJpaTest, Vitest)
  • Docker prostředí, Git workflow

Java 21 Spring Boot React TypeScript PostgreSQL Docker Git
